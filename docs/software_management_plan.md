## ⚠️ Risk Management Plan

- **Risk:** Poor communication between team members  
  **Mitigation:** Weekly meetings and WhatsApp group updates  

- **Risk:** Missed deadlines  
  **Mitigation:** Assign clear responsibilities and track progress regularly  

- **Risk:** Technical challenges (e.g., GitHub issues, coding errors)  
  **Mitigation:** Use online resources, collaborate, and seek help early  

- **Risk:** Unequal contribution from members  
  **Mitigation:** Monitor GitHub commits and assign tasks fairly

## 🛠️ Technology Stack

### Frontend:
- Figma
👉 Simple and suitable for building user interfaces quickly  

### Backend:
- Python
👉 Handles user requests, orders, and system logic  

### Database:
- MySQL 
👉 Stores user data, menu items, and orders  

### Version Control:
- Git & GitHub  
👉 Enables collaboration, version tracking, and project management  

---

## 📌 Reasoning for Technology Choices
The selected technologies are beginner-friendly, widely supported, and suitable for building a web-based application. They allow the team to collaborate efficiently while also being scalable enough to handle future improvements such as mobile integration or real-time tracking.

---

## 🧭 Development Approach
- Agile-inspired approach  
- Work in small tasks (features)  
- Regular updates and improvements  
- Continuous feedback from team members  

---

## 📊 Task Allocation Strategy
Each team member will be assigned specific responsibilities, but collaboration will be encouraged. Progress will be tracked using GitHub commits and regular team meetings.

---

## 📁 Version Control Plan
- All work will be uploaded to GitHub  
- Each member will contribute regularly  
- Changes will be committed with clear messages  
- Repository will be updated frequently to reflect progress  

---

## 📝 Conclusion
This management plan ensures that the project is well-organised, risks are minimised, and all team members contribute effectively. By following this structure, the team aims to successfully design and plan a functional cafeteria ordering system.
