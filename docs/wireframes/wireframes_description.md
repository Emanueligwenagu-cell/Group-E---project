# Wireframe UI Flow Description

## Overview

The wireframes represent the user interface flow of a food ordering web application that sells fried chips, drinks, and full meals. The design focuses on allowing users to quickly browse menu items, add food to the cart, and complete an order.

---

## 1. Home Page

The Home Page is the first screen users see when they visit the website.
It contains the logo, search bar, and navigation options. The page also shows featured food items and three main categories:

* Fried Chips
* Drinks
* Full Meals

Users can click a category or food item to view more details.

---

## 2. Menu Page

The Menu Page displays all available food items.
Users can filter items by category such as chips, drinks, or meals.

Each item shows:

* Food image placeholder
* Food name
* Price
* Add to Cart button

Users can select a food item to view detailed information.

---

## 3. Food Details Page

This page provides detailed information about a selected food item.
Users can view the food image, price, and description.

The user can:

* Choose the quantity
* Click the **Add to Cart** button

After adding the item, the user can proceed to the cart.

---

## 4. Cart Page

The Cart Page shows all selected food items before checkout.

The page displays:

* Item name
* Quantity
* Price
* Total cost

Users can update quantities or remove items from the cart.
They can then proceed to checkout.

---

## 5. Checkout Page

The Checkout Page allows users to complete their order.

Users must enter:

* Name
* Phone number
* Delivery address

They can select a payment method such as cash on delivery or card payment.

Once the user clicks **Place Order**, the order is submitted.

---

## 6. Order Confirmation

After placing the order, the system displays a confirmation message informing the user that the order was successfully placed.
