# Technology Stack

- Backend: Python
- Frontend: HTML, CSS, JavaScript
- Design Tool: Figma
- Database: MySQL
- Version Control / Collaboration: GitHub

## Justification
- Python: Chosen for its extensive ecosystem of libraries, full-featured frameworks and scalable web applications.
- Figma, HTML & CSS: Figma chosen for a structured approach for interactive interfaces, HTML & CSS for an expressive structure and responsive design.
- MySQL: Strong support for queries, relational database system and easy to integrate with Python.
- Github: Offers version control, supports Agile workflows and ensures accessibility for all team members
