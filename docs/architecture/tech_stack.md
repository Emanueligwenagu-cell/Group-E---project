# Technology Stack

- Backend: Python
- Frontend: Sigma, HTML & CSS
- Database: MySQL
- Hosting: Github

## Justification
- Python: Chosen for its extensive ecosystem of libraries, full-featured freameworks and scalable web applications.
- Sigma, HTML & CSS: Sigma chosen for structured approach for interactive interfaces, HTML & CSS for an expressive structure and responsive design.
- MySQL: Strong support for queries, relational database system and easy to integrate with Python.
- Github: Offers version control, supports Agile flows and ensures accessibility for all team members
