# System Decomposition

This section outlines the main components of the cafeteria system and their responsibilities.

---

## Modules

- User Management  
- Menu Management  
- Order Management  
- Payment Processing  
- Notification System  
- Admin Dashboard  

---

## Component Responsibilities

### User Management  
Handles user registration, login, and profile management for students and staff. It ensures that users can securely access the system and perform their actions.

### Menu Management  
Manages the display of available food items, including prices and availability. It ensures that users can view up-to-date menu options before placing orders.

### Order Management  
Handles the creation, processing, and tracking of orders placed by students. It ensures that orders are correctly recorded and sent to cafeteria staff for preparation.

### Payment Processing  
Manages payment transactions for orders. It ensures that payments are securely processed and confirmed before orders are completed.

### Notification System  
Sends updates to users regarding their orders, such as order confirmation and readiness for collection. This helps users stay informed without needing to check manually.

### Admin Dashboard  
Allows administrators to manage the system, including updating menus, monitoring orders, and handling system-related issues.
