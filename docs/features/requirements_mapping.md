# Feature to Requirements Mapping

## Feature: User Registration and Login

### Functional Requirements
- Users must be able to create an account or log in using valid credentials.
- The system must verify login details before allowing access.
- The system must show an error message if login details are incorrect.

### Non-Functional Requirements
- Login should respond within 2 seconds.
- User passwords must be stored securely.
- The login page must be simple and easy to use.

---

## Feature: Digital Cafeteria Menu

### Functional Requirements
- Users must be able to view available food items.
- The system must display food names, prices, and availability.
- Cafeteria staff should be able to update menu availability.

### Non-Functional Requirements
- Menu items should load quickly.
- The menu interface must be clear and user-friendly.
- The system should prevent unavailable items from being ordered.

---

## Feature: Food Ordering System

### Functional Requirements
- Users must be able to select food items and place an order.
- The system must allow users to choose quantity.
- The system must calculate the total order amount.

### Non-Functional Requirements
- Order placement should be reliable and accurate.
- The system should confirm orders immediately after submission.
- The ordering process should be easy to complete.

---

## Feature: Pickup or Delivery Option

### Functional Requirements
- Users must be able to choose either pickup or delivery.
- For delivery, users must enter/select their campus location.
- For pickup, users must receive an order number or confirmation.

### Non-Functional Requirements
- The selection process must be simple and clear.
- Delivery information must be stored accurately.
- The system should reduce confusion during collection or delivery.

---

## Feature: Order Status Tracking

### Functional Requirements
- Users must be able to see the status of their order.
- The system must show statuses such as Pending, Preparing, Ready for Pickup, Out for Delivery, and Completed.
- Cafeteria staff must be able to update order status.

### Non-Functional Requirements
- Order updates should display quickly.
- Status messages must be clear and understandable.
- The system should help reduce unnecessary queues at the cafeteria.

---

## Feature: Navigation System

### Functional Requirements
- Users must be able to move between pages such as Home, Menu, Orders, Login, and Profile.
- The navigation bar must be available on the main pages.
- Users must be able to return to the homepage easily.

### Non-Functional Requirements
- Navigation must be simple and consistent.
- The interface should work well on different screen sizes.
- Pages should load without unnecessary delay.

---

## Feature: Database Management

### Functional Requirements
- The system must store user information.
- The system must store menu items and prices.
- The system must store order details, delivery/pickup choice, and order status.

### Non-Functional Requirements
- Data must be stored securely.
- Data should be easy to retrieve when needed.
- The database structure must support future improvements.

---

## Feature: Admin/Cafeteria Staff Order Management

### Functional Requirements
- Cafeteria staff must be able to view incoming orders.
- Staff must be able to update order status.
- Staff must be able to manage available food items.

### Non-Functional Requirements
- The admin interface must be easy for staff to understand.
- The system must support multiple orders during busy periods.
- Staff actions should update the system accurately.
