# User Stories

## Student (Lihle)
- As a student, I want to browse the cafeteria menu in advance so that I can quickly decide what to order during my short break.  
- As a student, I want to place my order before my break starts so that my food is ready when I arrive.  
- As a student, I want to collect my prepared meal without waiting in line so that I can eat and still catch my shuttle on time.  
- As a student, I want to pay through the cafeteria app so that I don’t waste time at the counter.  

## Cafeteria Staff (Mr. Dlamini)
- As a cafeteria staff member, I want to view incoming student orders so that I can prepare meals ahead of time.  
- As a cafeteria staff member, I want to organize orders by collection time so that students receive their meals promptly.  
- As a cafeteria staff member, I want to reduce congestion at the counter so that the serving process is smoother.  
- As a cafeteria staff member, I want to track completed and pending orders so that I can manage workflow efficiently.

## System Administrator (Ayanda)
- As a system administrator, I want to update the daily menu so that students always see the correct options.  
- As a system administrator, I want to adjust item availability so that students don’t order meals that are out of stock.  
- As a system administrator, I want to ensure pricing information is accurate so that students are charged correctly.  
- As a system administrator, I want to monitor system activity so that I can quickly resolve technical issues.  
- As a system administrator, I want to maintain system reliability so that both students and staff can depend on it.
