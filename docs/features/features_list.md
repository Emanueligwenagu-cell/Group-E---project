# Features List - Ibhotwe Food Ordering Platform

## 1. Overview
Ibhotwe is a campus-focused food ordering platform designed to connect university students with nearby food vendors. The system prioritises affordability, speed, and accessibility, enabling students to browse, order, and receive meals efficiently within a campus environment.

Features have been identified based on user roles (students, vendors, and administrators), core system requirements, and operational feasibility within a university ecosystem.

---

## 2. Core MVP Requirements

### Student Module
- User authentication (student registration, login, and session management)
- Profile management (student details, campus affiliation)
- Food catalogue browsing (list of available meals from vendors)
- Category-based filtering (fast food, traditional meals, snacks, healthy options)
- Shopping cart functionality (add/remove items, quantity updates)
- Order placement and checkout process
- Basic payment handling (cash on delivery, card, or mobile payment simulation)
- Order status tracking (pending, preparing, ready, completed)

### Vendor Module
- Vendor registration and authentication
- Menu management (CRUD operations for food items)
- Order management interface (accept/reject/update order status)

### System Core
- Campus-based vendor discovery (location or campus mapping logic)
- Basic notification system (order status updates)

---

## 3. Should Have Features (Enhanced Functionality)

### Student Experience Enhancements
- Discount engine for student deals and promotions
- Search functionality (keyword-based food search)
- Ratings and review system for vendors and meals
- Push/email notifications for order updates

### Vendor Enhancements
- Sales dashboard (daily/weekly order summaries)
- Popular item analytics (most ordered meals)
- Pre-order scheduling support (time-based order fulfilment)

### System Enhancements
- Group ordering functionality (multi-user cart aggregation)
- Advanced filtering (price range, popularity, preparation time)

---

## 4. Could Have Features (Future Iterations / Scalability)

### Engagement & Retention
- Loyalty points system (reward-based incentives for repeat purchases)
- Referral system (student-to-student promotion tracking)
- Gamified rewards (badges, discounts, achievements)

### Logistics & Delivery
- Campus-based delivery system using student couriers
- Real-time delivery tracking (GPS-based updates)

### Intelligence Layer
- Recommendation engine (collaborative filtering based on order history)
- Demand prediction for vendors (peak meal times analytics)

### Platform Expansion
- Event-based food promotions (campus events, exam season bundles)
- Digital wallet system (preloaded student balance for faster checkout)

---

## 5. Prioritisation Rationale
Features are prioritised based on:

- **User impact**: Student ordering flow is the primary value driver.
- **Technical feasibility**: MVP avoids complex logistics (e.g., real-time tracking).
- **Business viability**: Vendor onboarding and order processing are critical for platform operation.
- **Scalability**: Advanced features are deferred to later iterations once product-market fit is established.

---

## 6. Summary
The MVP version of Ibhotwe focuses on enabling a complete end-to-end food ordering cycle between students and vendors, while maintaining a simple and efficient user experience. Secondary and tertiary features are structured to support future scaling into a full campus commerce ecosystem.
